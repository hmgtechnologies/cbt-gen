Deployment in plain steps

How to use the generated ZIP

  1. Download ZIP from this generator.
  2. Extract it on your computer.
  3. Create Supabase project for the client or use the one entered in the generator.
  4. Run COMPLETE_SQL_SETUP.sql in Supabase SQL Editor.
  5. Upload extracted files to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static host.
  6. Open deployment_validator.html in the generated site.
  7. Test teacher → admin approval → exam → student result before real exams.
